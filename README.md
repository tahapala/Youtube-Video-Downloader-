# Youtube-Video-Downloader-
What you need for a YouTube video downloader.
First, download FFmpeg from the link I provided. (The source you are downloading from is an official and secure source). Then, right-click on the downloaded folder and select "Extract All". Double-click on the "bin" folder within the extracted folder and copy its contents. The steps you need to take are detailed in the attachments.

Place the three files you copied into the folder you created for YouTube Video Downloader. The next step is to install an extension that allows cookies for YouTube. You need to install a browser extension with the name "Get cookies.txt LOCALLY". In the extension you added, click the export or download option and drag the downloaded file into the YouTube video downloader folder. The steps you need to take are detailed in the attachments.
